CLI Command Cheat Sheet
Python 3.10+ 
# 1. View all available models and presets:
python magic_cli.py models

# 2. Enhance image with EsMagic (Default):
python magic_cli.py enhance input.jpg -o output.png

# 3. Enhance image with specific preset (e.g. Crisp Portrait, Night Restore):
python magic_cli.py enhance photo.jpg -o photo_enhanced.png --preset crisp_portrait

# 4. Batch enhance an entire directory:
python magic_cli.py batch ./photos/ -o ./enhanced/

# 5. Run Generative AI Super-Resolution (Replicate Real-ESRGAN 4x):
python magic_cli.py enhance photo.jpg -o ai_4k.png --mode ai --provider replicate --model real-esrgan --scale 4 --api-key "r8_..."
